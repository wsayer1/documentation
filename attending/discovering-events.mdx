The **Explore** page is where you find events to attend. It shows every **public, upcoming event** across Gathere, with the soonest ones first. Events that have already started drop off the list automatically.

## Browse

Each event appears as a card showing its cover image, title, date and time, location, and how many people are going. Select any card to open its full event page.

## Search by name

Use the search box at the top to filter the list to events whose title matches what you type. The list narrows as you type.

## Filter by location

Three buttons let you narrow the list:

- **All** — every public event.
- **In person** — events happening at a physical venue.
- **Online** — events happening over a meeting link.

<Note>
  Private events never appear on Explore. You can only reach a private event if the host shares its link with you. See [Public and private events](/hosting/event-visibility).
</Note>

## Nothing showing up?

If no events match, you'll see a friendly "No upcoming events found" message. Try clearing your search, switching the filter back to **All**, or checking back later — or [host the first one yourself](/hosting/creating-an-event).
