Anyone with an account can host. Creating an event is done through a single form.

## Start a new event

Go to **My events** and choose **Create event**. A form opens where you fill in the details.

## Fill in the details

<Steps>
  <Step title="Title and description">
    Give your event a clear **title** and a **description** telling guests what to expect.
  </Step>
  <Step title="Where it happens">
    Choose **In person** and enter a venue address, or choose **Online** and paste a meeting link. The meeting link is only ever shown to guests who register.
  </Step>
  <Step title="When it happens">
    Set the **start** date and time. An **end** time is optional.
  </Step>
  <Step title="Cover image (optional)">
    Paste the web address of an image to use as the event's cover. Leave it blank for a clean colored cover.
  </Step>
  <Step title="Capacity (optional)">
    Set a maximum number of guests, or leave it empty for unlimited. When a limited event fills up, extra guests join a [waitlist](/attending/waitlists) automatically.
  </Step>
  <Step title="Visibility">
    Choose **Public** or **Private** — see [Public and private events](/hosting/event-visibility).
  </Step>
</Steps>

## Publish or save as a draft

- **Publish event** makes it live: public events appear on Explore, and anyone with the link can register.
- **Save as draft** keeps it private to you so you can finish it later. Drafts show up under **My events** with a _Draft_ label and aren't visible to anyone else.

<Tip>
  You can edit any detail later — opening a published event to make changes won't unpublish it. See [Managing an event](/hosting/managing-an-event).
</Tip>
