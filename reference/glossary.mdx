<ResponseField name="Event">
  A gathering someone hosts — a meetup, talk, workshop, or meet-and-greet. Events are always free.
</ResponseField>

<ResponseField name="Host">
  The member who created an event and manages it. Anyone with an account can be a host.
</ResponseField>

<ResponseField name="Guest">
  A member who registers for an event. The same person can host some events and be a guest at others.
</ResponseField>

<ResponseField name="Register">
  To reserve your spot at an event. Free and instant.
</ResponseField>

<ResponseField name="Waitlist">
  The line you join when a limited event is already full. If a confirmed guest cancels, the person waiting longest is moved up automatically.
</ResponseField>

<ResponseField name="Check in">
  A host marking a guest as arrived on the day of the event. It's just for the host's own tracking.
</ResponseField>

<ResponseField name="Draft">
  An event the host is still preparing. Drafts are visible only to the host until they're published.
</ResponseField>

<ResponseField name="Published">
  An event that's live. Guests can open it and register.
</ResponseField>

<ResponseField name="Cancelled">
  An event the host called off. Registration is closed and it shows a cancelled label.
</ResponseField>

<ResponseField name="Public event">
  An event listed on the Explore page for every member to find.
</ResponseField>

<ResponseField name="Private event">
  An event that isn't listed anywhere and can only be reached through its shared link.
</ResponseField>

<ResponseField name="Saved event">
  An event you've bookmarked to revisit later. Your saves are private to you.
</ResponseField>

<ResponseField name="Explore">
  The home screen for signed-in members, listing all public, upcoming events.
</ResponseField>

<ResponseField name="Announcement">
  A short update a host posts to an event, seen by the host and the event's registered guests.
</ResponseField>
