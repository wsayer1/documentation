<AccordionGroup>
  <Accordion title="Are events free?">
    Yes. Every event on Gathere is free — there are no paid tickets and no payment step.
  </Accordion>

  <Accordion title="Do I get an email when I register or when something changes?">
    Not yet. Gathere doesn't send emails. Keep track of everything inside the app: check **My tickets** for your registrations and the event page for updates from the host.
  </Accordion>

  <Accordion title="Who can see the events I've registered for?">
    Only you. Your registrations are private. A host can see the guest list for their own event, but no one can see your full list of tickets.
  </Accordion>

  <Accordion title="When do I get the meeting link for an online event?">
    After you register. The meeting link stays hidden until you have a confirmed spot, then it appears right on the event page.
  </Accordion>

  <Accordion title="What happens if an event is full?">
    You join the waitlist automatically. If a confirmed guest cancels, the person waiting longest is moved up to a confirmed spot. See [Waitlists](/attending/waitlists).
  </Accordion>

  <Accordion title="Can I be both a host and a guest?">
    Absolutely. The same account can host its own events and register for others.
  </Accordion>

  <Accordion title="How do people find a private event?">
    Only through its link. Private events aren't listed on Explore, so share the link with the people you want to invite. See [Public and private events](/hosting/event-visibility).
  </Accordion>

  <Accordion title="Can I change an event after publishing it?">
    Yes. Open it from **My events** and edit any detail. Editing a published event keeps it published.
  </Accordion>

  <Accordion title="Who can see my profile?">
    Signed-in members only. Signed-out visitors can't see profiles — on a public event page viewed while signed out, the host shows as "the organizer".
  </Accordion>
</AccordionGroup>
